# ai-marketing-student-resources
Free guides, checklists and templates for students learning SEO, AEO, GEO and digital marketing in the AI era.
## Why this repo?

Search now includes AI-generated answers, and employers want marketers who can use AI tools and show real results. This repo puts the basics in one place so you can learn, practice, and build a portfolio for free.

## Who is it for?

- Students and beginners in digital marketing
- Career switchers
- Anyone building a first portfolio

## Quick start

1. Read the learning roadmap
2. Run the SEO audit checklist on your own blog
3. Apply the AEO content checklist to your next post
4. Plan your posts with the content calendar template
5. Pick a portfolio project and document your results

## Core concepts

| Term | Meaning | Starter tip |
|---|---|---|
| **SEO** | Search Engine Optimization: ranking in search results | Target one main keyword per page |
| **AEO** | Answer Engine Optimization: being the direct answer | Answer the question in the first two sentences |
| **GEO** | Generative Engine Optimization: being mentioned in AI responses | Keep facts and author details accurate and consistent |

These areas overlap. Start with SEO basics, then add AEO and GEO.

## Suggested learning order

`SEO basics → AEO → Content writing → Analytics → Paid ads`

## Free tools to start with

- Google Search Console
- Google Analytics 4
- Google Keyword Planner and Google Trends
- Screaming Frog (free version has a URL limit)
- Canva for graphics
- ChatGPT or Claude for brainstorming (always fact-check)

> Free plans and limits change often. Check each tool's website for current details.

## Portfolio project ideas

- [ ] Publish a 3-post mini blog
- [ ] Run an SEO check on a small site and list 5 fixes
- [ ] Create a 2-week social media content calendar
- [ ] Write 3 versions of ad copy and explain which you would test first
- [ ] Write a one-page results summary for each project

## Using AI responsibly

- Use AI to brainstorm, outline, and edit, not to publish raw output
- Verify facts, numbers, and links
- Add your own examples and opinions
- Be open about where AI helped
